# DESIGN-SYSTEM.md — Дизайн-система Толкучки (tolkuchka)

Единый стиль проекта. **Все страницы и компоненты сверяются с этим документом.** Создаётся один раз на старте, дальше только уточняется.

> Технология: Nuxt UI v4 + Tailwind CSS v4 (`tailwindcss` — явная зависимость, отдельного `tailwind.config` нет). Токены — CSS-first через `@theme` в `app/assets/css/main.css`; семантические цвета и компонентная тема — `app/app.config.ts`.

---

## 1. Принципы

1. **Grayscale-first** — сначала иерархия (размер, вес, цвет текста), цвет подключаем последним
2. **Ограниченные шкалы** — только значения из шкал ниже, никаких произвольных `padding: 13px`
3. **Щедрые отступы** — начинаем с большого пространства, убираем по необходимости
4. **Консистентность** — никаких хардкод-цветов, только токены из этого документа
5. **Доступность** — контраст WCAG 2.1 AA: текст 4.5:1, крупный 3:1, focus-кольца видимы

## 2. Цвета

### Светлая тема

| Токен | Значение | Использование |
|-------|----------|---------------|
| `bg` | `#ffffff` | Фон страницы |
| `bg-subtle` | `#f8fafc` | Альтернативный фон секций |
| `text` | `#111827` (gray-900) | Основной текст |
| `text-muted` | `#6b7280` (gray-500) | Вторичный текст |
| `text-light` | `#9ca3af` (gray-400) | Капишены, подписи |
| `border` | `#e5e7eb` (gray-200) | Разделители |

### Тёмная тема (не инвертируем!)

| Токен | Значение | Использование |
|-------|----------|---------------|
| `bg` | `#0f172a` (slate-900) | Фон страницы |
| `bg-subtle` | `#1e293b` (slate-800) | Карточки, поверхности |
| `text` | `#f8fafc` (slate-50) | Основной текст |
| `text-muted` | `#94a3b8` (slate-400) | Вторичный текст |
| `text-light` | `#64748b` (slate-500) | Капишены |
| `border` | `#334155` (slate-700) | Разделители |

**Правила тёмной темы:**
- Фон — тёмно-серый/сланцевый, **не чисто чёрный** (`#000000` запрещён)
- Возвышение (elevation) — через светлее поверхность, а не тень (тени в тёмной не видны)
- Акцентные цвета — светлее и чуть десатурированные

### Бренд-палитра (primary)

Зелёный — «живой», подходит маркетплейсу (рост, товары, экология).

Палитра бренда — вариант **A «Свежий»** (выбран 2026-08-20): **primary = `emerald`**, **secondary = `blue`**, **neutral = `slate`**. Совпадает со шкалами Tailwind по умолчанию, дополнительные шкалы не нужны:

```ts
// app/app.config.ts
export default defineAppConfig({
  ui: {
    colors: {
      primary: 'emerald',  // ← основной цвет бренда (зелёный)
      secondary: 'blue',   // ← вторичный (ссылки, вторичные действия)
      neutral: 'slate',    // ← текст, бордеры, фоны
    },
  },
})
```

### Action-цвет (контраст кнопок)

Стоковый emerald-500 (`#10b981`) даёт белый текст с контрастом всего **2.5:1** — провал AA. Поэтому `--ui-primary` (главные кнопки, ссылки, focus) переопределяется на более тёмные оттенки:

| Тема | `--ui-primary` | Контраст с белым | Контраст с фоном |
|------|----------------|------------------|------------------|
| light | `emerald-700` (`#047857`) | **5.5:1** ✅ | 5.5:1 (на белом) |
| dark | `emerald-600` (`#059669`) | 3.8:1 (крупный ✅) | **4.7:1** ✅ (на slate-900) |

В тёмной теме акцент светлее и чуть менее насыщенный (правило возвышения светлотой) — принятый компромисс: текст-ссылки проходят AA, текст кнопок — для крупного. Переопределение — в `app/assets/css/main.css`, вне CSS-слоёв (чтобы перебивать дефолты Nuxt UI):

```css
/* Вариант A: action-цвет primary и точные токены из §2 */
:root, .light {
  --ui-text: #111827;                              /* slate-900 */
  --ui-primary: var(--ui-color-primary-700);       /* emerald-700 */
}
.dark {
  --ui-text: #f8fafc;                              /* slate-50 */
  --ui-border: #334155;                            /* slate-700 */
  --ui-primary: var(--ui-color-primary-600);       /* emerald-600 */
}
```

> Если понадобится нестандартная шкала — задать в `app/assets/css/main.css` через `@theme static` (обязательно полный диапазон `--color-<name>-50 … 950`), затем указать имя цвета в `ui.colors`. Nuxt UI разрешает только цвета, существующие в теме.

### Семантические утилиты (Tailwind-токены из `@theme`)

Чтобы не писать `text-(--ui-text-muted)`, в `@theme` заведены алиасы. **Использовать только их**, без прямых `--ui-*` в классах:

| Утилита | Назначение | Ссылается на |
|---------|-----------|--------------|
| `bg-page` | Фон страницы | `--ui-bg` |
| `text-content` | Основной текст | `--ui-text` |
| `text-muted` | Вторичный текст | `--ui-text-muted` |
| `text-dimmed` | Капишены, подписи | `--ui-text-dimmed` |
| `text-toned` | Основной текст на `bg-subtle` | `--ui-text-toned` |
| `bg-subtle` | Альтернативный фон | `--ui-bg-muted` |
| `bg-elevated` | Карточки, поверхности | `--ui-bg-elevated` |
| `border-line` | Разделители | `--ui-border` |
| `border-line-muted` | Мягкие разделители | `--ui-border-muted` |

### Семантические цвета (из коробки Nuxt UI)

| Цвет | Назначение |
|------|------------|
| `success` | Успех, оплачено, доставлено |
| `warning` | Предупреждения, ожидает подтверждения |
| `error` | Ошибки, отменено |
| `info` | Информация |

**Правило:** семантические состояния (статусы заказов, ошибки валидации) — только через `success/warning/error`, **никогда** новые hex-цвета.

### Текст: 3 уровня

| Уровень | Светлая | Тёмная | Использование |
|---------|---------|--------|---------------|
| Основной | `text-content` (slate-900) | `text-content` (slate-50) | Заголовки, ключевые значения |
| Вторичный | `text-muted` (slate-500) | `text-muted` (slate-400) | Подписи, описания, лейблы форм, микротекст |
| Лёгкий | `text-dimmed` (slate-400) | `text-dimmed` (slate-500) | Только декоративный текст и disabled-состояния |

**Контраст (WCAG AA):** читаемый текст — минимум 4.5:1 (обычный) / 3:1 (крупный 18px+ или bold). `text-dimmed` на белом не проходит 4.5:1 — для любого читаемого текста использовать минимум `text-muted`.

## 3. Типографика

### Шрифты

Два семейства максимум:
- **Заголовки:** Inter (600/700)
- **Текст:** Inter (400/500) — или одно семейство с вариацией веса

Базовый шрифт задаётся токеном Tailwind в `app/assets/css/main.css` (Inter подключается self-hosted через `@fontsource-variable/inter` — без сетевых запросов):

```css
/* app/assets/css/main.css */
@import "@fontsource-variable/inter";

@theme {
  --font-sans: "Inter Variable", system-ui, sans-serif;
}
```

Заголовки и текст — одно семейство: иерархия через вес и размер, не через смену шрифта.

### Модульная шкала (1.2)

| Стиль | Размер | Вес | Line-height | Tailwind |
|-------|--------|-----|-------------|----------|
| Display | 36px | 700 | 1.1 | `text-4xl font-bold leading-tight` |
| H1 | 30px | 700 | 1.2 | `text-3xl font-bold` |
| H2 | 24px | 600 | 1.25 | `text-2xl font-semibold` |
| H3 | 20px | 600 | 1.3 | `text-xl font-semibold` |
| H4 | 18px | 600 | 1.4 | `text-lg font-semibold` |
| Body | 16px | 400 | 1.75 | `text-base leading-relaxed` |
| Small | 14px | 400 | 1.5 | `text-sm` |
| Caption | 12px | 500 | 1.5 | `text-xs font-medium` |

### Правила

- **Иерархия через 1 рычаг** — крупный ИЛИ жирный ИЛИ тёмный, не всё сразу; «всё сразу» — только для самого важного элемента страницы
- Заголовки: `leading-tight` (1.0–1.25), текст: `leading-relaxed` (1.5–1.75)
- Не использовать вес ниже 400 для основного текста
- Метки и заголовки таблиц — **де-эмфазированы**: маленькие, светлее данных (`text-xs uppercase tracking-wide text-gray-400`)
- Цены, метрики дашборда — крупным значением, контекст — маленьким

## 4. Отступы и сетка

### Шкала отступов (только эти значения!)

`4px` `8px` `16px` `24px` `32px` `48px` `64px`

```ts
// Tailwind-классы
p-1 (4)  p-2 (8)  p-4 (16)  p-6 (24)  p-8 (32)  p-12 (48)  p-16 (64)
gap-2    gap-4    gap-6     gap-8     gap-12
```

### Правила отступов

- Отступы **между группами > отступы внутри группы**
- Связанные элементы (иконка + текст) — `gap-2` (8px)
- Секции карточки — `gap-6` (24px)
- Крупные секции страницы — `gap-12`/`gap-16` (48–64px)
- Начинаем с «слишком много белого пространства» и убираем

### Сетка и ширина

| Контейнер | Ширина | Tailwind |
|-----------|--------|----------|
| Страница | 1280px | `max-w-7xl mx-auto` |
| Контент (текст) | 65ch | `max-w-prose` |
| Формы | 300–500px | `max-w-md` / `max-w-lg` |
| Карточка товара | фиксированный aspect-ratio | `aspect-[3/4]` |

### Breakpoints

| Брейкпоинт | Tailwind | Сетка каталога |
|------------|----------|----------------|
| Mobile | `sm` (640) | 2 колонки |
| Tablet | `md` (768) | 3 колонки |
| Desktop | `lg` (1024) | 4 колонки |
| Wide | `xl` (1280) | 4–5 колонок |

**Mobile-first:** пишем для мобильных, расширяем брейкпоинтами вверх.

## 5. Радиусы и тени

### Радиусы

| Уровень | Значение | Где |
|---------|----------|-----|
| `rounded-md` | 6px | Кнопки, инпуты |
| `rounded-lg` | 8px | Карточки |
| `rounded-xl` | 12px | Модалки, крупные карточки |
| `rounded-full` | — | Аватары, бейджи |

### Тени (масштаб возвышения)

| Уровень | Tailwind | Элемент |
|---------|----------|---------|
| Поднят слегка | `shadow-sm` | Кнопки, карточки |
| Плавающий | `shadow-lg` | Дропдауны, попапы |
| Выше всех | `shadow-xl` | Модалки |

**Правила:**
- Не перегружать тенями — если всё «плавает», глубины нет
- Цвет тени — прозрачный тёмный, не серый
- В тёмной теме: возвышение через светлее фон (`bg-slate-800`), тени минимальны

| Алерты / сообщения страницы | `UAlert` |

### Варианты кнопок (иерархия)

| Уровень | Вариант | Использование |
|---------|---------|---------------|
| Primary | `color="primary" variant="solid"` | Главное действие |
| Secondary | `color="gray" variant="outline"` | Вторичное действие |
| Tertiary | `variant="ghost"` / ссылка | Третичное, текст-действие |

### Иконки

- Набор: **Heroicons** (поставляется с Nuxt UI)
- Размеры: `w-4 h-4` (inline), `w-5 h-5` (навигация), `w-6 h-6` (крупные)
- Одинаковая толщина stroke в пределах контекста

### Формы

- **Лейблы вторичны к значениям** (не конкурируют с данными): глобально через `app.config.ts` → `ui.formField.slots.label = 'block text-xs font-medium text-muted'`; без CAPS (плохо для кириллицы)
- Микротекст форм (юридические строки, подсказки под полями): `text-xs/sm text-muted`, не ниже
- Инлайн-ошибки — сообщения из zod-схем (`shared/schemas/`), позиция под полем через `UFormField`
- Все инпуты на всю ширину колонки формы: `class="w-full"` (в v4 инпуты не растягиваются по умолчанию)

## 7. Состояния (Loading / Empty / Error)

### Загрузка

- **Скелетоны** (`USkeleton`) — для данных, загружаемых на сервере (`useAsyncData`), структура повторяет контент
- **Спиннер** (`USpinner`) — для действий в процессе (отправка формы)
- На кнопках при сабмите: `loading` + `disabled`

### Пустые состояния

- Иллюстрация/иконка + короткий текст + **одно явное действие (CTA)**
- Пример: корзина пуста → иконка корзины + «Ваша корзина пуста» + `UButton` «Перейти в каталог»

### Ошибки

- Ошибки форм — инлайн под полем через `UFormGroup` (не общий блок сверху)
- Ошибки сервера — `useToast` + `color="error"`
- Страница-ошибка — `app/error.vue` (глобальная) и `app/pages/[...slug].vue` (404 catch-all) в стиле проекта

## 8. Layout-паттерны

### Общие правила

- **Выравнивание по левому краю** по умолчанию. По центру — только hero, короткие заголовки, CTA, empty states
- Страница: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`
- Отступ между секциями страницы: `py-12`/`py-16`
- Изображения: `object-fit: cover`, фиксированный `aspect-ratio`, никогда не растягивать

### Структура страниц маркетплейса

```
AppHeader (UHeader: лого, поиск, корзина, тема, профиль + CTA «Стать продавцом» → /seller)
  └── main (max-w-7xl)
       ├── [breadcrumbs] UBreadcrumb
       ├── [заголовок страницы]
       └── [контент]
AppFooter
```

### Auth-layout (`app/layouts/auth.vue`)

Минимальный layout для `/auth/login` и `/auth/register` — без AppHeader/AppFooter:

- Лого по центру сверху (иконка + «Толкучка», кликабелен → `/`)
- Форма — центрированная карточка `max-w-md`
- Мини-футер: Приватность · Условия · Контакты (`text-sm text-muted`)

Почему не default: целостность воронки (гость из чекаута не отвлекается навигацией), шапка всё равно неполноценна для гостя, паттерн «безопасной зоны» как у крупных площадок. Подключение: `definePageMeta({ layout: 'auth' })`.

### Dashboard-layout (`app/layouts/dashboard.vue`)

Каркас кабинета продавца (`/seller/*`) на компонентах dashboard-кита Nuxt UI. Спринт 1 — заглушки, реальное содержимое — спринт 3:

```
UDashboardGroup
  ├── UDashboardSidebar (collapsible)
  │     ├── #header: лого (иконка + «Толкучка» → /), текст скрывается при коллапсе
  │     ├── UNavigationMenu vertical (Дашборд · Товары · Заказы)
  │     └── #footer: «На витрину» → / (при коллапсе — только иконка)
  └── UDashboardPanel
        └── UDashboardNavbar: #leading = UDashboardSidebarCollapse, #right = ThemeToggle
              └── #body: <slot />
```

Правила:

- **Без title в navbar** — каждая страница рендерит свой H1 в теле; navbar рендерит title как `<h1>`, дублировать нельзя
- Слоты сайдбара принимают `{ collapsed }` — кастомный контент (тексты лого и футера) обязан на него реагировать, иначе вылезает за узкую колонку
- Иконкам лого — `shrink-0`; пункты меню — из `UNavigationMenu :items`, активный подсвечивается автоматически
- Подключение: `definePageMeta({ layout: 'dashboard' })`

## 9. Чек-лист сверки любой новой страницы

Перед мержем каждой фичи — проверить:

- [ ] Дизайн работает «размытым» (blur test) — иерархия читается без цветов
- [ ] Работает в grayscale — цвет не делает работу иерархии
- [ ] Достаточно белого пространства, отступы из шкалы (4/8/16/24/32/48/64)
- [ ] Только токены из раздела «Цвета» — нет случайных hex
- [ ] Типографика из модульной шкалы, метки де-эмфазированы
- [ ] Ширина контента ограничена (`max-w-prose` для текста)
- [ ] Контраст: текст ≥ 4.5:1, крупный ≥ 3:1 (и в светлой, и в тёмной)
- [ ] Тёмная тема: фон не чёрный, возвышение светлотой, акценты светлее
- [ ] Компоненты — из карты Nuxt UI (раздел 6), не самописные
- [ ] Loading (USkeleton), empty, error состояния присутствуют
- [ ] Адаптив: mobile-first, сетка каталога по breakpoints
- [ ] Тени только из масштаба, возвышение уместно

## 10. Частые ошибки (не допускать)

| Ошибка | Причина | Фикс |
|--------|---------|------|
| «Выглядит как поделка» | Мало белого, произвольная ширина | Больше отступов, ограничить ширину |
| «Плоско» | Нет глубины | Мягкие тени, border-bottom секций |
| «Текст не читается» | Плохой line-height, низкий контраст | `leading-relaxed`, контраст ≥ 4.5:1 |
| «Всё одинаковое» | Нет иерархии | Варьировать размер/вес/цвет |
| «Пёстро» | Случайные цвета | Только палитра из раздела 2 |
| Произвольные значения | `padding: 13px` | Только шкала отступов |
| Чёрный фон в тёмной | Харш, «светится» текст | `#0f172a`, не `#000000` |
