# 08. Корзина (`/cart`)

Статус: 🔍 согласован

Уровень: **сложный** (JTBD + CRO — воронка к checkout)

## Job (JTBD)

- **Функциональный:** «Когда я выбрал несколько товаров у разных продавцов, я хочу видеть их вместе, скорректировать количество/убрать лишнее и понять итоговую сумму, чтобы принять решение об оформлении»
- **Эмоциональный:** контроль расхода («ничего не потеряю, всё посчитано»)
- **Социальный:** чувствовать себя расчётливым покупателем («трачу осознанно, а не импульсивно»)

### Силы (Push / Pull / Anxiety / Habit)

| Сила | В чём | Ответ интерфейса |
|------|-------|------------------|
| Push | Держать товары в голове/вкладках и считать в уме — утомляет | Всё выбранное в одном месте, суммы пересчитываются сами |
| Pull | Прозрачная сводка до оформления | Подытог + итого всегда видны (sticky на mobile) |
| Anxiety | «Цена изменится / товар закончится, пока решаю»; «потрачу лишнее» | `stock` виден и ограничивает количество; цены актуальны из БД |
| Habit | Купить сразу на карточке и не возвращаться | Корзина сохраняется между сессиями (localStorage → синхронизация при входе) |

**Конкуренты за job:** список покупок в заметках, скриншоты товаров, «купить сразу», отложенные вкладки, не покупать сейчас. Корзина выигрывает, если к ней вернуться проще, чем вести список вручную.

**Little Hire:** корзина — повторяемое действие (не разовый Big Hire). Удержание = лёгкость возврата к сохранённой корзине и мгновенный пересчёт, а не само оформление.

## Блоки интерфейса (по CRO)

1. **Заголовок** «Корзина» + счётчик позиций (высокий)
2. **Список позиций:** фото (ссылка на товар), название, цена за единицу, количество `UInputNumber` (мин 1, макс stock), сумма строки, удалить (`UButton ghost` с `Icon` корзины); при `stock ≤ 5` — подпись «осталось N шт.» (высокий)
3. **Сводка** (`UCard`): подытог, доставка (позже — заглушка «рассчитывается при оформлении»), **итого** крупно (высокий)
4. **CTA «Оформить заказ»** (`UButton` primary, полной ширины в сводке) → `/checkout`; микроподпись под кнопкой «Доставка и итог уточнятся на следующем шаге» — снимает тревогу обязательства (высокий)
5. **CTA «Продолжить покупки»** (ghost) → `/products` (средний)
6. **Empty state:** `UEmpty` (иконка корзины + «Корзина пуста» + CTA «Перейти в каталог») (средний)

## UX-правила

- Все изменения количества/удаление — без перезагрузки (Pinia `useCartStore` + `useCart`), тост при удалении
- Изменение количества не может превышать `stock` (иначе блокировка с подсказкой)
- Товар, ставший недоступным (`isActive=false` или `stock=0`) после добавления: показывается приглушённо с бейджем «Нет в наличии», исключается из суммы; кнопка оформления блокируется, пока позиция не удалена — в checkout не передаётся битых позиций
- Суммы пересчитываются мгновенно; итого всегда виден (sticky на mobile)
- Для неавторизованного: корзина хранится в Pinia (localStorage), при авторизации — синхронизация с `CartItem` (флоу решается в задаче #30)

## Технический каркас

- **Layout:** default; **middleware:** нет (корзина клиентская, auth не обязателен для просмотра)
- **Рендеринг:** SSR (контент — клиентский, из Pinia); SEO: `robots: noindex`
- **Состояния:** `USkeleton` при подгрузке цен; empty state; ошибка сервера — `useToast color="error"`
- **Ссылки:** входящие — header (иконка корзины с бейджем количества), кнопка «В корзину» на товаре; исходящие — `/checkout`, `/products`, `/products/[slug]`
- **API:** `GET /api/cart` (список + join Product), `POST /api/cart` (добавить/инкремент), `PATCH /api/cart/[id]` (изменить количество), `DELETE /api/cart/[id]`

## Сверка с дизайн-системой

- Соответствует. Список + сводка: 2 колонки на desktop, стопкой на mobile
- **Иерархия сумм** (blur test): метки «Подытог»/«Доставка» — `text-sm text-muted`; значения строк — `font-medium`; **итого** — `text-2xl font-semibold` (единственный элемент «всё сразу»)
- **Отступы:** строки списка `gap-4` (связанные), список ↔ сводка `gap-8` (группы), сводка `p-6`
- Удаление позиции — ghost-кнопка с нейтральной иконкой (semantic color ≠ visual weight; красным не кричит), бейдж «Нет в наличии» — `UBadge color="error" variant="subtle"`
- Sticky-сводка на mobile: `bg-page` + `border-line` сверху, CTA всегда в зоне большого пальца
