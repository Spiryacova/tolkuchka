# 01. Главная (`/`)

Статус: 🔍 согласован

Уровень: **сложный** (лендинг, JTBD + CRO)

## Job (JTBD)

- **Функциональный:** «Когда я хочу что-то купить, но ещё не знаю что именно, я хочу быстро найти интересные товары и уйти в каталог/категорию, чтобы не рыскать вслепую»
- **Эмоциональный:** почувствовать «здесь живая и понятная площадка, где легко выбрать»
- **Социальный:** быть тем, кто «находит лучшее у независимых продавцов» (для продавца: «я веду настоящий магазин, а не барахолку»)

**Вторичный job:** продавец попадает на `/` → должен найти путь в лендинг `/seller`.

### Силы (Push / Pull / Anxiety / Habit)

| Сила | В чём | Ответ интерфейса |
|------|-------|------------------|
| Push | Крупные маркетплейсы перегружены, чужие правила для продавцов | Простая площадка: поиск + категории на первом экране |
| Pull | «Живая толкучка» онлайн: разнообразие независимых продавцов | Популярные товары как витрина разнообразия |
| Anxiety | «Продавцы-частники — надёжно ли?» | Блок «Почему Толкучка» (возвраты, доставка), имя продавца на карточках |
| Habit | Привычный крупный маркетплейс / офлайн-рынок | Мгновенная ценность без регистрации: поиск работает сразу |

**Конкуренты за job:** крупные маркетплейсы, соцсети-барахолки, офлайн-рынки, «не покупать сейчас». Главная выигрывает, если ведёт вглубь быстрее, чем вкладка соцсети.

**Little Hire:** главную открывают повторно; метрика успеха — доля ушедших в каталог/карточку с первого экрана, а не сам заход.

## Блоки интерфейса (по CRO)

1. **Hero** — заголовок-ценностное предложение + поиск (главный вход) + CTA «Смотреть товары»; под поиском — примеры запросов чипами («кастрюля», «подарок», «велосипед» → клик = переход в `/products?search=…`), снимает трение «не знаю, что искать». Один главный путь для «готовых покупать». (Приоритет: высокий)
2. **Категории** — сетка карточек категорий → `/categories/[slug]`. Путь «ещё не решил, что нужно» (высокий)
3. **Популярные товары** — сетка `ProductCard` → `/products/[slug]`; в шапке секции ссылка «Все товары →» → `/products`. Социальное доказательство «у людей покупают» (высокий)
4. **Почему Толкучка** — 3 преимущества (доставка, выбор продавцов, возвраты) — снятие возражений (средний)
5. **Баннер продавца** — CTA «Стать продавцом» → `/seller`, рядом строка-доверие («товары, заказы и статистика — в одном кабинете») (вторичный job, низкий)

> Социальное доказательство числами («N товаров от M продавцов») добавить в hero, когда появятся реальные данные — не раньше.

## UX-правила

- Поиск в hero сразу в фокусе на мобильных? Нет — фокус только по клику (избегать автопрокрутки)
- Категории и товары кликабельны целиком (не только текст)
- Скелетоны на месте загружаемых блоков (категории, товары)

## Компоненты Nuxt UI

- `UInput` (поиск) → переход в каталог с query `search=`
- `UButton` (primary «Смотреть товары», ghost «Стать продавцом», soft — чипы-примеры запросов)
- `UCard` (карточки преимуществ и категорий; при появлении специфики у категорий — доменный `CategoryCard`)
- `ProductCard` (кастомный доменный компонент — в карте Nuxt UI нет аналога)
- `USkeleton` (загрузка категорий/товаров)

## Затрагиваемые сущности

- ✅ `Category` — список категорий (+ опциональный `imageUrl`: без картинки — фолбэк-иконка)
- ✅ `Product` — популярные товары (`isActive`, популярность = агрегат `_count.orderItems`, как в 02-catalog)
- ✅ `User` — имя продавца в `ProductCard`
- ❌ нет — не требуется

## Технический каркас

- **Layout:** default; **middleware:** нет
- **Рендеринг:** SSR (контент для ботов); SEO: `useSeoMeta` (title «Толкучка — покупайте и продавайте», description, OG)
- **Состояния:** `USkeleton` для категорий и товаров (`useAsyncData` с ключами)
- **Ссылки:** входящие — AppHeader/AppFooter; исходящие — `/categories/[slug]`, `/products/[slug]`, `/products?search=`, `/seller`
- **API:** `GET /api/categories`, `GET /api/products?limit=8&sort=popular`

## Сверка с дизайн-системой

- Соответствует. Hero — по центру (единственное исключение из left-align); контент `max-w-7xl mx-auto`; секции `py-12/py-16`
- Hero: заголовок Display (`text-4xl font-bold leading-tight`), подзаголовок `text-lg text-muted`, поиск `max-w-md` по центру; чипы-примеры — `UButton variant="soft" size="sm"` (кликабельны → кнопки, не бейджи)
- Секционные заголовки — H2 слева, служебная ссылка («Все товары →») справа (`flex justify-between items-baseline`)
- Карточки категорий: с картинкой — `aspect-[3/4] object-cover` (§4); без — фолбэк-иконка на `bg-subtle`, чтобы сетка не «мигала» высотами
