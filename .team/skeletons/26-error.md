# 26. Глобальная ошибка (`app/error.vue`)

Статус: 🔍 согласован

Уровень: **простой**

## Job (JTBD)

- Пользователь столкнулся с ошибкой (500, сеть, сбой) и хочет понять, что случилось, и иметь способ перезапустить/вернуться.

## Блоки интерфейса

1. Заголовок с кодом ошибки (де-эмфазированно)
2. Краткий текст «Что-то пошло не так»
3. CTA «Обновить страницу» (primary, `clearError` + reload) + «На главную» (ghost)

## UX-правила

- По центру (short headline + CTA)
- Логирование ошибки на сервер (в консоль/мониторинг), но не показывать стек пользователю
- `clearError({ redirect: '/' })` для возврата на главную

## Компоненты Nuxt UI

- `UButton`, `Icon`

## Затрагиваемые сущности

- ❌ не требуются

## Технический каркас

- **Layout:** минимальный (без AppHeader/AppFooter — страница ошибки рендерится вне layout)
- **Рендеринг:** SSR/CSR; SEO: `robots: noindex`
- **Состояния:** — (статическая)
- **Ссылки:** входящие — любая ошибка приложения; исходящие — reload, `/`

## Сверка с дизайн-системой

- Соответствует. Empty-state-паттерн §7; тёмная тема работает (не чёрный фон)
