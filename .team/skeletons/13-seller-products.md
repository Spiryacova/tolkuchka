# 13. Товары продавца (`/seller/products`)

Статус: 🔍 согласован

Уровень: **сложный** (JTBD + UX)

## Job (JTBD)

- **Функциональный:** «Когда у меня много товаров, я хочу видеть их список с ценой/остатком/статусом и управлять ими (редактировать, скрыть), чтобы каталог оставался актуальным»
- **Эмоциональный:** контроль «я управляю магазином»; Социальный: — (инструмент)

## Блоки интерфейса

1. **Заголовок** «Мои товары» + CTA «Добавить товар» (`UButton` primary) → `/seller/products/new` (высокий)
2. **Поиск** `UInput` по названию + фильтр по статусу `UTabs` (все / активные / скрытые). Счётчики табов считаются с учётом поиска; в заголовке — общее число товаров продавца (без учёта поиска) (средний)
3. **Таблица** `UDataTable`: фото (`UAvatar`/`NuxtImg`), название, категория, цена, остаток, статус `UBadge` (активен→success / скрыт→gray; `stock = 0` → error «Закончился»), действия в `UDropdownMenu` («⋯») с подписанными пунктами — Редактировать, Скрыть/Показать, Удалить (иконки без подписей нечитаемы) (высокий)
4. **Пагинация** `UPagination` (средний)
5. **Empty states** — два разных: (а) товаров нет вообще → `UEmpty` + CTA «Добавить первый товар»; (б) ничего не найдено по поиску/фильтру → `UEmpty` «Ничего не найдено» + сброс фильтра. Смешивать нельзя — разные причины, разные действия (средний)

## UX-правила

- Все операции — через API продавца (`/api/sellers/products`), сервер фильтрует по sellerId сессии
- Скрытие (toggle isActive) — обновление строки после ответа сервера (не оптимистично: при ошибке интерфейс не врёт о состоянии), тост; пункт блокируется на время запроса (защита от двойного клика)
- **Удаление — с ограничением:** доступно только для товара без заказов (FK на OrderItem); у товара с заказами пункт «Удалить» задизейблен с пояснением «Есть заказы — скройте товар» — остаётся «Скрыть». Удаление подтверждается `UModal` («Товар нельзя вернуть»)
- Редактирование → `/seller/products/[id]/edit`
- Данные продавца НЕ дублируют каталог — отдельный endpoint продавца

## Технический каркас

- **Layout:** dashboard; **middleware:** `seller` (+ серверная проверка роли)
- **Рендеринг:** SSR; SEO: `robots: noindex`
- **Состояния:** `USkeleton` строк таблицы; empty state
- **Ссылки:** входящие — dashboard, `/seller/products/new`; исходящие — `/seller/products/new`, `/seller/products/[id]/edit`
- **API:** `GET/PATCH/DELETE /api/sellers/products`

## Сверка с дизайн-системой
