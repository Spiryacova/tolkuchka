# 03. Карточка товара (`/products/[slug]`)

Статус: 🔍 согласован

Уровень: **средний** (JTBD кратко + CRO)

## Job (JTBD)

- «Когда я нашёл подходящий товар, я хочу быстро оценить его (цена, фото, описание, продавец) и добавить в корзину, чтобы не потерять и продолжить выбор»
- Эмоциональный: уверенность «я не прогадаю»; Социальный: продавец внушает доверие

## Блоки интерфейса (по CRO)

1. **Breadcrumbs** `UBreadcrumb` (домашняя → категория → товар) (низкий)
2. **Галерея** `ProductGallery` (кастомный: главное фото + миниатюры, `aspect-[3/4]`) (высокий)
3. **Инфо-блок:** название, цена крупно (`text-xl/2xl`), наличие (`UBadge` success/error по `stock`), рейтинг (заглушка — бэклог `Review`) (высокий)
4. **CTA-блок:** количество (`UInputNumber`, мин 1, макс stock) + «В корзину» (`UButton` primary, при добавлении — `useToast` «Добавлено» с действием «Перейти в корзину») (высокий)
5. **Описание** — `max-w-prose` (средний)
6. **Продавец** — карточка: `UAvatar` + имя + «Товары продавца» → `/sellers/[slug]` (средний, решает доверие)
7. **Доставка/возвраты** — `UAccordion` (снятие возражений) (низкий)
8. **Похожие товары** — 4 `ProductCard` из той же категории (`categoryId`, исключая текущий); удержание, если товар не подошёл; можно MVP+1 (низкий)

## UX-правила

- Кнопка «В корзину» disabled при `stock = 0` («Нет в наличии»)
- При `stock < 5` — badge «Осталось N» (дефицит), не обманывать
- Добавление в корзину — без перезагрузки страницы (Pinia), тост-подтверждение с переходом в корзину
- Страница может отдаться из ISR-кэша с устаревшим `stock` — актуальность проверяется на сервере при добавлении в корзину (`POST /api/cart` валидирует `stock`)
- Изображения lazy (`NuxtImg`), fallback при отсутствии

## Компоненты Nuxt UI

- `UBreadcrumb`, `UBadge`, `UInputNumber`, `UButton`, `UAvatar`, `UCard`, `UAccordion`, `useToast` (с действием-переходом)
- `ProductGallery` (кастомный)

## Затрагиваемые сущности

- ✅ `Product` (связанная `Category` для breadcrumb), `User` (продавец, `slug`/`bio`)
- ✅ `CartItem` — добавление (Pinia → `POST /api/cart`)
- ⬜ `Review` — блок рейтинга/отзывов (бэклог, пока заглушка «скоро»)

## Технический каркас

- **Layout:** default; **middleware:** нет
- **Рендеринг:** SSR + ISR (routeRules `swr`); SEO: `useSeoMeta` (title = товар, description = описание, OG:image = первое фото)
- **Состояния:** `USkeleton` (галерея + инфо); `createError({ statusCode: 404 })` если товар не найден/неактивен
- **Ссылки:** входящие — каталог, категория, главная, поиск; исходящие — `/categories/[slug]` (breadcrumb), `/sellers/[slug]`, `/cart`
- **API:** `GET /api/products/[slug]`

## Сверка с дизайн-системой

- Соответствует. Двухколоночный layout (галерея | инфо) на desktop, стопкой на mobile; `aspect-[3/4]`
- Иерархия: название H1 (`text-2xl font-semibold`); цена + количество + CTA сгруппированы в одной зоне (близость = связь), цена `text-2xl font-semibold` — крупным только эти два элемента
- Breadcrumbs — `text-xs text-dimmed` (навигация, не контент); заголовки аккордеона — `text-sm`
- «Похожие товары» — та же сетка `gap-6`, что в каталоге
