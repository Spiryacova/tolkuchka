# 04. Категория (`/categories/[slug]`)

Статус: 🔍 согласован

Уровень: **средний** (JTBD кратко)

## Job (JTBD)

- **Функциональный:** «Когда я знаю, в какой категории искать, я хочу увидеть её товары целиком, чтобы выбрать, не переключаясь между разделами»
- **Эмоциональный:** спокойствие «всё из этой категории — в одном месте, ничего не пропущу»
- **Социальный:** — (слабо применим; социальный сигнал остаётся в сортировке «популярные» внутри сетки)

## Блоки интерфейса

1. **Breadcrumbs** `UBreadcrumb` (домашняя → категория) (низкий)
2. **Заголовок категории** + краткое описание (`useSeoMeta` привязана к названию) (средний)
3. **Сетка товаров** `ProductCard` (та же, что в каталоге, отфильтрована по категории; сортировка наследуется от переиспользуемого блока каталога) (высокий)
4. **Пагинация** `UPagination` (средний)
5. **CTA** «Смотреть все товары» → `/products` (переход к полным фильтрам) (низкий)
6. **Empty state** `UEmpty` «В категории пока пусто» → каталог (средний)

## UX-правила

- Переиспользовать компонент каталога (сетка + пагинация) — не дублировать
- Хлебные крошки обязательны (SEO + навигация)
- Если категории нет — `createError` 404

## Компоненты Nuxt UI

- `UBreadcrumb`, `ProductCard` (кастомный), `UPagination`, `UButton`, `USkeleton`, `UEmpty`

## Затрагиваемые сущности

- ✅ `Category` (по `slug`, `imageUrl` для шапки — опционально), `Product` (по `categoryId`)

## Технический каркас

- **Layout:** default; **middleware:** нет
- **Рендеринг:** ISR (routeRules `swr`); SEO: title = «{Категория} — Толкучка», OG
- **Состояния:** `USkeleton`; empty state; 404 для несуществующей категории
- **Ссылки:** входящие — главная (сетка категорий), футер, breadcrumb; исходящие — `/products/[slug]`, `/products`
- **API:** `GET /api/categories/[slug]` (категория + товары; query: `page`, `sort` — как в каталоге)
