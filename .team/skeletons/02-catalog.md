# 02. Каталог (`/products`)

Статус: 🔍 согласован

Уровень: **сложный** (JTBD + CRO)

## Job (JTBD)

- **Функциональный:** «Когда мне нужно конкретное (или примерное) — от кастрюли до подарка, я хочу отфильтровать товары по категории/цене/поиску и сравнить варианты, чтобы выбрать лучший по цене и качеству»
- **Эмоциональный:** контроль и лёгкость («не утонуть в 1000 товарах»)
- **Социальный:** найти «то, что у людей хорошо покупают» (сортировка по популярности — сигнал); чувствовать себя тем, кто выбирает разумно

### Силы (Push / Pull / Anxiety / Habit)

| Сила | В чём | Ответ интерфейса |
|------|-------|------------------|
| Push | Десятки вкладок и магазинов, сравнение в уме | Фильтры + сортировка сужают выдачу за секунды |
| Pull | Быстро увидеть «лучшее под мой запрос» | Мгновенная фильтрация без перезагрузки, URL делится состоянием |
| Anxiety | «Переплачу»; «продавец ненадёжен, товар не придёт» | Сортировка по популярности (социальное доказательство), имя продавца на карточке |
| Habit | Привычный крупный маркетплейс / офлайн-рынок | Скорость и предсказуемость: скелетоны, состояние в URL, ноль тупиков |

**Конкуренты за job:** крупные маркетплейсы, офлайн-рынок, рекомендации в соцсетях, «не покупать сейчас». Выигрывает тот, кто быстрее сводит «примерную потребность» к 2–3 конкретным вариантам.

**Little Hire:** каталог открывают повторно; удержание = скорость сужения выбора и релевантность выдачи, а не первый заход.

## Блоки интерфейса (по CRO)

1. **Заголовок + счётчик** «N товаров» + активные фильтры (сбрасываемые `UBadge`-чипы) (высокий)
2. **Панель фильтров** (sidebar на desktop / раскрытие на mobile): категории (`UCheckbox`/`USelect`), диапазон цены (`URangeSlider`), наличие/в наличии (`USwitch`), поиск по названию (`UInput`) (высокий)
3. **Сортировка** `USelect`: популярные / новизна / цена ↑ / цена ↓ (средний); «популярные» = агрегат `_count.orderItems` (сколько раз товар куплен)
4. **Сетка товаров** `ProductCard` (grid 2/3/4 колонки по breakpoints) (высокий)
5. **Пагинация** `UPagination` (средний)
6. **Empty state** «Ничего не найдено» + CTA «Сбросить фильтры»; ниже — fallback «Популярные сейчас» (3–4 `ProductCard`), чтобы поиск не заканчивался тупиком (средний)

## UX-правила

- Фильтры и пагинация синхронизированы с URL (`useUrlSearchParams`) — состояние не теряется при перезагрузке/шаринге ссылки
- Изменение фильтров → мгновенный запрос (`useAsyncData` с ключом от параметров), скелетоны при загрузке
- Кнопка «Сбросить фильтры» видна, только если фильтры активны
- Сортировка по умолчанию — «популярные»
- `ProductCard`: быстрое действие «В корзину» на карточке (hover на desktop, всегда видимо на mobile) — сокращает путь к корзине без захода в карточку товара (уточняется в спеке ProductCard, 03)

## Компоненты Nuxt UI

- `UCheckbox`, `URangeSlider`, `USwitch`, `UInput`, `USelect`, `UPagination`, `UBadge` (чипы фильтров), `USkeleton`
- `ProductCard` (кастомный доменный компонент)
- Мобильные фильтры — `USlideover` или `UDrawer` + `UButton`

## Затрагиваемые сущности

- ✅ `Product` — список, фильтры (categoryId, price, search, isActive), пагинация
- ✅ `Category` — список для фильтра
- ✅ `User` — имя продавца в `ProductCard`
- ✅ популярность — без нового поля: агрегат `_count.orderItems` по связи `Product.orderItems` (решение 2026-08-21, вариант «переиспользовать»; при росте нагрузки → денормализация `salesCount`)

## Технический каркас

- **Layout:** default; **middleware:** нет
- **Рендеринг:** ISR (routeRules `swr: 3600`) — кэширует базовый `/products`; выдача с query-фильтрами (`?category=…&search=…`) рендерится на лету, в кэш базовой страницы не попадает; SEO: `useSeoMeta` (title «Каталог», canonical, OG)
- **Состояния:** `USkeleton`-сетка при загрузке; empty state; `createError` 404 не требуется (пустой каталог = empty state)
- **Ссылки:** входящие — AppHeader поиск, hero `/`, категории `/categories/[slug]`, `ProductCard`; исходящие — `/products/[slug]`
- **API:** `GET /api/products` (query: category, minPrice, maxPrice, search, sort, page, limit)

## Сверка с дизайн-системой

- Соответствует. Сетка: 2/3/4 колонки; отступы `gap-6`; фильтры слева, контент справа; `max-w-7xl`
- **Скелетоны повторяют итоговую сетку** (те же колонки и высоты карточек) — без layout shift при загрузке
- Фильтры: метки групп де-эмфазированы (`text-xs uppercase tracking-wide text-dimmed`), панель `sticky` на desktop; чипы активных фильтров — `UBadge` с крестиком `text-xs`
- Счётчик «N товаров» — рядом с заголовком, `text-muted` (не конкурирует с H1)
- Карточки: изображение `aspect-[3/4] object-cover` (по дизайн-системе §4), empty state по центру (допустимое исключение)
