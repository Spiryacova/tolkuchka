# 25. 404 (`/[...slug]`)

Статус: 🔍 согласован

Уровень: **простой**

## Job (JTBD)

- Пользователь попал на несуществующий адрес (ошибка, битая ссылка) и хочет вернуться к полезному контенту без тупика.

## Блоки интерфейса

1. Иконка/визуал 404 (де-эмфазированно)
2. Короткий текст «Страница не найдена» + пояснение
3. CTA «Перейти в каталог» (primary) + «На главную» (ghost)

## UX-правила

- По центру (short headline + single CTA — разрешено)
- Не блуждающий юзер: всегда 2 выхода (каталог + главная)
- HTTP-статус 404 (через `createError`), не 200

## Компоненты Nuxt UI

- `UButton`, `Icon` (i-heroicons-question-mark-circle)

## Затрагиваемые сущности

- ❌ не требуются

## Технический каркас

- **Layout:** default; **middleware:** нет
- **Рендеринг:** SSR; SEO: `robots: noindex`
- **Состояния:** — (статическая)
- **Ссылки:** входящие — любая битая ссылка; исходящие — `/products`, `/`

## Сверка с дизайн-системой

- Соответствует. Empty-state-паттерн из §7: иконка + текст + одно явное действие
