# 19. История покупок (`/account/orders`)

Статус: 🔍 согласован

Уровень: **средний** (JTBD кратко)

## Job (JTBD)

- «Когда я хочу узнать, где мой заказ или что я покупал раньше, я хочу видеть список своих заказов со статусами, чтобы отслеживать без звонков в поддержку»

## Блоки интерфейса

1. Заголовок «Мои заказы» (средний)
2. **Список/таблица заказов:** номер, дата, сумма (итого), статус `UBadge` (цвет по `OrderStatus`: PENDING→warning, CONFIRMED/SHIPPED→info, DELIVERED→success, CANCELLED→error), ссылка на детали; сортировка по дате — новые сверху (высокий)
3. **Пагинация** `UPagination` (средний)
4. **Empty state** «Заказов пока нет» + CTA «Перейти в каталог» (средний)

## UX-правила

- Таблица: де-эмфазированные заголовки, данные — основное (`text-sm/base`)
- Каждый статус — семантический цвет, без новых hex
- Строка кликабельна целиком → `/account/orders/[id]`

## Компоненты Nuxt UI

- `UDataTable` (или `UCard`-список), `UBadge`, `UPagination`, `UButton`, `USkeleton`

## Затрагиваемые сущности

- ✅ `Order` (по buyerId), `OrderItem` (для суммы/позиций), `User`

## Технический каркас

- **Layout:** default; **middleware:** `auth`
- **Рендеринг:** SSR; SEO: `robots: noindex`
- **Состояния:** `USkeleton` (строки таблицы); empty state
- **Ссылки:** входящие — `/checkout/success`, header (профиль → заказы); исходящие — `/account/orders/[id]`, `/products`
- **API:** `GET /api/orders` (только свои — фильтр по сессии)
